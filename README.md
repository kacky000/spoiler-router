# Spoiler Router

An entry for [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) on make.fun.

`main.ts` writes one line to `/output/entry.txt`: a protective home router explaining why the film stopped right before the twist.

Run it with `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`).
